# 🎬 فُرجه - Furja Live Streaming Platform

**تطبيق بث مباشر متكامل يجمع بين البث المباشر والتفاعل المباشر مع المشاهدين**

## 📋 المميزات الرئيسية

### 🎥 البث والبث المباشر
- بث مباشر عالي الجودة (720p, 1080p, 4K)
- دعم متعدد الكاميرات
- تأثيرات بصرية وفلاتر احترافية
- جودة تكيفية (Adaptive Bitrate)

### 💬 التفاعل المباشر
- درد شة مباشرة في الوقت الفعلي
- تفاعلات فورية (Like, Emoji)
- الهدايا والمكافآت
- منشئ المحتوى والمشاهدين

### 💰 نظام الدفع والهدايا
- شراء الهدايا الافتراضية
- تحويل النقاط إلى أموال
- نظام العمولات
- دعم طرق الدفع المتعددة

### 👥 ملفات المستخدمين
- ملفات شخصية احترافية
- متابعة والمتابعون
- سجل البث والإحصائيات
- إعدادات الخصوصية والأمان

### 🔔 الإشعارات
- إشعارات البث المباشر
- تنبيهات التفاعلات
- رسائل شخصية
- إشعارات الأنظمة

### 📊 لوحة التحكم والإحصائيات
- إحصائيات البث في الوقت الفعلي
- تحليل المشاهدين
- الدخل والإحصائيات المالية
- تقارير الأداء

### 🎨 التخصيص والمحتوى
- ملفات شخصية قابلة للتخصيص
- سجل البث والفيديوهات
- قوائم التشغيل
- البث المجدول

### 🔐 الأمان والمراقبة
- نظام المصادقة الآمن
- التحقق من الهوية
- نظام المراقبة والإبلاغ عن الانتهاكات
- حماية البيانات

## 🚀 البدء السريع

### المتطلبات
- Node.js 16+
- PostgreSQL 13+
- Redis 6+
- Docker & Docker Compose

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/CimaFire/furja.git
cd furja

# تثبيت الحزم
npm install

# إعداد متغيرات البيئة
cp .env.example .env

# تشغيل Docker
docker-compose up -d

# تشغيل الخادم
npm run dev
```

## 🛠️ تقنيات مستخدمة

### Backend
- **Node.js** - بيئة التشغيل
- **Express.js** - إطار العمل
- **Socket.io** - البث المباشر والدردشة
- **PostgreSQL** - قاعدة البيانات
- **Redis** - التخزين المؤقت
- **JWT** - المصادقة
- **Stripe** - معالجة الدفع

### Frontend
- **React.js** - مكتبة الواجهة
- **Redux** - إدارة الحالة
- **Tailwind CSS** - تصميم
- **Axios** - طلبات HTTP
- **WebRTC** - البث

### Mobile
- **React Native** - تطوير التطبيق
- **Expo** - البيئة السريعة
- **Redux** - إدارة الحالة

### DevOps
- **Docker** - التسليم
- **Docker Compose** - تنسيق الخدمات
- **GitHub Actions** - الأتمتة
- **AWS** - الاستضافة
